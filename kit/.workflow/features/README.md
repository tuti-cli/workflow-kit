# Archived Features

> Completed feature plans. Created by `issue-closer` when issue closes.

---

## Naming

```
YYYY-MM-DD-feature-slug.md
```

Example:
```
2026-03-18-user-authentication.md
```

---

## Structure

Each archived feature includes:
- Original plan
- Actual outcome (what was done vs planned)
- Issue/PR links

---

## Usage

These archives serve as:
- Historical record of what shipped
- Reference for similar future features
- Input for `skill-evolver` (v3)
