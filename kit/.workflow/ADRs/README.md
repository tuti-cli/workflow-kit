# Architecture Decision Records

> ADRs are permanent records of significant architecture decisions.
> Written via `/ww:arch decide`.
> Never delete — supersede with new ADR instead.

---

## What Goes Here

Significant architectural decisions affecting codebase structure, patterns, or approaches.

**Good ADR candidates:**
- Choosing between architectural patterns
- Selecting packages for cross-cutting concerns
- Defining domain boundaries
- Backward-incompatible changes

**Not ADR candidates:**
- Routine feature decisions
- Bug fix approaches
- Minor refactors

---

## Naming

```
NNN-short-title.md
```

Examples:
```
001-use-sanctum-for-api-auth.md
002-service-layer-pattern.md
```

---

## Status

- **Proposed** — under discussion
- **Accepted** — decided and active
- **Deprecated** — being phased out
- **Superseded by ADR-NNN** — replaced
